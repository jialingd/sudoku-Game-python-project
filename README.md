# Jialing-Deng
A short description of the project:
Welcome to the game Sudoku: Survive The Doomsday. The game took place in 23th centry, where the world's largest research center is invaded by a group of aliens. To start the emergency device which help kill the intruders, the user is required to solve a sudoku puzzle. The sudoku puzzle has 3 levels of difficulty with 2 levels of hints, and the user can also open the auto-candidate mode to check all the legal values in each cell. If the user press "l", the board will be transformed to a letter board. 


How to run the project:
To run the project, the user should open main.py, screen1.py and screen2.py in the editor.


Which libraries you are using that need to be installed, if any.
The user should install basic libraries such as os and sys, also import basic modules: random, math, copy, and itertools. 



A list of any shortcut commands that exist.

Press keys from 1 to 9 to enter a value on the board if it is in number mode; press keys from "A" to "E" if it is in letter mode instead.
Press the left key to undo a move and right key to remove a move. 
press "t" to vary the board by swapping rows and cols.
press "s" to return to the initial board.
press "backspace" to delete the value you just entered.
press "r" to return to the main page. 
press "l" to change between letter mode and number mode. 
The user can click on the "check answer" button directly and if the board is not fulfilled or the answer is incorrect, the game over page will show up.
